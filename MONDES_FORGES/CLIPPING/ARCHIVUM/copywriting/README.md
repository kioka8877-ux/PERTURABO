## 8 sous-dossiers

### 1. `hooks_library/`

Types de hooks + exemples annotés :
- `types.md` — taxonomy : question, declaration, stat choc, mystery, contradiction, cible-naming...
- `by_platform.md` — dominance par plateforme (TT, YT Shorts, Reels)
- `by_market.md` — nuances culturelles par marché
- `examples.md` — exemples annotés (puise dans `demons/`)

### 2. `title_formulas/`

Formules de titres :
- `hormozi.md` — "N façons de..." / "Si tu fais Y, voici Z..."
- `ogilvy.md` — promesse + spécificité
- `iman_gadzhi.md` — aspiration overdelivery
- `reframing.md` — teaser + transformation de sens
- `applicability.md` — matrice formule × plateforme × marché

### 3. `caption_frameworks/`

Structures de caption :
- `paragraph_magic.md` — structure du paragraphe reframing 2 lignes
- `caption_structure.md` — caption patterns (spacing, emojis, vertical comma)
- `reframe_patterns.md` — patterns : highlight→motivation, rires→dramatisation, etc.
- `anti_lengths.md` — longueurs mortes (long-court-longue = killed)

### 4. `subliminal_language/`

SAVOIR SECRET :
- `words_tests.md` — mots qui pressent des boutons cognitifs
- `phonetic_patterns.md` — allitération, assonance, répétition d'voyelle
- `cadence.md` — 1-2 temps, 3 temps, creux-pic
- `rhetoric.md` — question rhétorique vs engagement, déclaration d'autorité

### 5. `slang_by_market/`

Codex slang :
- `us_young_english_2026.md` — slang US jeune vivant + morts
- `tiktok_shadowban_terms.md` — termes bannis TT (reviewed)
- `cultural_references.md` — créateurs phares, événements, memes viables

### 6. `hashtags_research/`

Stratégie hashtags :
- `3_strates.md` — large + moyen + niche (ex : #fitness + #grindset + #disciplineculture)
- `by_platform.md` — TT vs YT Shorts vs Reels (algos différents)
- `banned_recent.md` — hashtags shadowbannés récents
- `rotation_strategy.md` — éviter SAT (Same-Hashtag Syndrome)

### 7. `on_screen_text_patterns/`

Texte affiché dans la vidéo à keyframe précise :
- `positioning.md` — top, center, bottom — règles
- `timing.md` — 0.5s, 1s après hook, etc.
- `color_readability.md` — couleur + readability sur la source
- `reframing_on_screen.md` — phrase qui transforme le sens quand elle apparaît
- `max_per_clip.md` — max 1 (overdose = clutter)

### 8. `reference_clips_titles/`

Titres de clips qui ont percé — indexés titre (pas clip entier) :
- `<clip_id>_title.md` — `{ url, title, platform, views, angle_observed }`
- Index puise dans `ARCHIVUM/demons/`
